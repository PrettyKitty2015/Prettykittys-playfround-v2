# PrettyKitty’s Playground — Setup Instructions

## What This Is
A real Next.js application foundation for your AI character creation and storytelling platform.
Branding is locked to the approved crimson Maine Coon aesthetic.

## Prerequisites (All Free)
1. Install Node.js: https://nodejs.org (LTS version)
2. Create a free GitHub account: https://github.com
3. Create a free Supabase account: https://supabase.com
4. Create a free Vercel account: https://vercel.com (for later deployment)

## Local Setup
1. Download this entire `prettykittys-playground` folder.
2. Open a terminal in the folder.
3. Run: `npm install`
4. Run: `npm run dev`
5. Open http://localhost:3000
